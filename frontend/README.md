# Bonesy Personal Helper Frontend

This is a Next.js frontend for the Bonesy Personal Helper application. It provides a web-based interface for debugging and development, allowing you to interact with the same API endpoints that the Raspberry Pi application uses.

## Getting Started

First, install the dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Available Scripts

- `npm run dev` - Runs the app in development mode
- `npm run build` - Builds the app for production
- `npm run start` - Runs the built app in production mode
- `npm run lint` - Runs ESLint to check for code issues

## Features

- Basic landing page with "Hello World" greeting
- Next.js setup with TypeScript support
- Responsive design with modern styling
- Development and production build support
